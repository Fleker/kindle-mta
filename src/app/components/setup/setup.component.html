Quick Start

Add these parameters to the URL:

ParamDescriptionExample
subway Subway GTFS stop IDs (comma-separated) R16N,R16S
bus Bus stop IDs (comma-separated) 308984
walk Walk time in minutes per stop R16N:5,308984:8
labels Custom display name per stop R16N:Times Sq NB
n Max arrivals per route (default: 4) 4
busKey MTA Bus Time API key (for bus stops) abc123
proxy CORS proxy URL prefix (required) https://corsproxy.io/?url=
refresh Auto-refresh interval in seconds (default: 60) 60

Finding Stop IDs

  • Subway: Download the MTA GTFS static data from mta.info/developers. Open stops.txt and look up your station. The stop ID ends in N (uptown) or S (downtown).
  • Bus: Find your stop on the MTA Bus Time map at bustime.mta.info. The numeric stop ID appears in the URL or popup.

CORS Proxy

MTA APIs do not allow direct browser access (CORS). You need a proxy. The simplest free option is corsproxy.io — just add &proxy=https://corsproxy.io/?url= to your URL.

For a more reliable setup, deploy a free Cloudflare Worker proxy and pass its URL as proxy.

Bus API Key

Bus arrivals require a free MTA Bus Time API key. Register at bustime.mta.info/wiki/Developers/Index. Subway and alerts work without any key.
